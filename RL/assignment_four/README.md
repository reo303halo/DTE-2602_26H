# Q-Learning Demo

A small demo of Q-learning on a 5x5 grid. The agent learns to walk from S to G and avoid the pits (X).

## How to run

1. Install Python 3 and NumPy:

   ```bash
   pip install numpy
   ```

2. Open a terminal in the project folder and start the program:

   ```bash
   python main.py
   ```

3. Make the terminal window big enough (at least 100 x 24 characters). Press `Ctrl+C` to quit.

## Change the settings

Open `parameters.py`, change the values, save, and run `python main.py` again.
